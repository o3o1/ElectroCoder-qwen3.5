Boost升压转换器数字PID控制算法实现

1. PID控制器结构体定义：
typedef struct {
    double Kp;          // 比例增益
    double Ki;          // 积分增益
    double Kd;          // 微分增益
    double integral;    // 积分项累加值
    double prev_error;  // 上一次误差值
} PIDController;

2. PID更新函数：
double pid_update(PIDController *pid, double error, double dt) {
    double proportional = pid->Kp * error;                    // 比例项
    pid->integral += error * dt;                              // 积分累加
    double integral = pid->Ki * pid->integral;                // 积分项
    double derivative = pid->Kd * (error - pid->prev_error) / dt; // 微分项
    pid->prev_error = error;                                  // 更新上次误差
    return proportional + integral + derivative;              // PID输出
}

3. 占空比限制函数：
double limit_duty(double duty) {
    if (duty < 0.05) return 0.05;    // 最小占空比5%
    if (duty > 0.95) return 0.95;    // 最大占空比95%
    return duty;
}

4. Boost转换器输出电压模型：
double simulate_vout(double duty, double noise) {
    return VIN / (1.0 - duty) + noise;  // Vout = Vin/(1-D) + 噪声
}

算法特点：
1. 完整的数字PID控制实现
2. 占空比限制保护

4. 微分项防止超调
5. 适用于实时嵌入式系统
